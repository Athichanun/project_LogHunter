## 📁 โครงสร้างโฟลเดอร์ใน `src`
* `src/assets/` - ไฟล์ประกอบหน้าเว็บ (ภาพนิ่ง, รูปโลโก้, เวกเตอร์)
* `src/components/` - คอมโพเนนต์ที่ใช้ร่วมกันบ่อยๆ (เช่น `Navbar`, `Footer`, `GlassCard` การ์ดสไตล์กระจกใส)
* `src/pages/` - หน้าเว็ปแยกตามโมดูล (เช่น หน้าแรก `Home`, หน้าจัดการ `Dashboard`)
* `src/context/` - การจัดการสถานะร่วม (Global State) เช่น ธีมสว่าง/มืด และข้อมูลผู้ใช้งานระบบ
* `src/hooks/` - คลัง Logic ย่อยสำหรับแยกไปใช้ซ้ำ (เช่น `useLocalStorage` ตัวเซฟข้อมูลลงในเบราว์เซอร์)
* `src/services/` - ไฟล์รวมฟังก์ชันและตัวช่วยส่งค่าแบบ REST API เชื่อมกับฝั่ง Back-end (`src/services/api.ts`)
* `src/utils/` - ฟังก์ชันเล็กๆ ในการจัดระเบียบข้อมูล (เช่น จัดการวันที่ภาษาไทย)

## 🚀 วิธีการรันระบบเพื่อพัฒนาต่อ (Local Development)

### 1. การเปิดรันบนเครื่องตนเอง
เปิด Terminal แล้วเข้าไปในโฟลเดอร์ `front_end` จากนั้นรันคำสั่ง:
```bash
npm install
npm run dev
```
หลังจากรันเสร็จ เว็บไซต์จะแสดงผลที่ลิงก์: **`http://localhost:5173`**

### 2. การคอมไพล์เพื่อใช้งานจริง (Production Build)
เมื่อระบบเสร็จสมบูรณ์ สามารถแปลงไฟล์ให้มีความจุเล็กลงและรวดเร็วสำหรับการเอาไปขึ้น Server ได้ด้วยคำสั่ง:
```bash
npm run build
```
ผลลัพธ์จะไปแสดงในโฟลเดอร์ `dist` สำหรับให้คุณหยิบไป Deploy ต่อครับ
